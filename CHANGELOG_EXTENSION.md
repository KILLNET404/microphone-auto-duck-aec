# Chromium Extension — история изменений

## 0.7.5 — первая сборка, подготовленная к публикации

- Самостоятельное расширение Manifest V3 без менеджера userscript.
- Автоматическое приглушение HTML5-плееров и восстановление исходной громкости.
- Ползунок остаточной громкости 0–100% с шагом 1%, значение по умолчанию 5%, локальное сохранение настроек.
- Пересчёт громкости от исходного уровня без промежуточного восстановления при изменении ползунка.
- Быстрый переключатель приглушения и зелёный/красный индикатор на значке расширения.
- Синхронизация состояния между вкладками и поддерживаемыми фреймами; независимые сессии микрофона.
- Поддержка динамических HTML5-плееров и открытых Shadow DOM.
- Запрос отключения AEC в поддерживаемых случаях.
- Компактное горизонтальное меню на русском и английском языках.

Расширение и userscript имеют независимую историю версий. Промежуточные тестовые сборки UI1–UI7 не являются отдельными публичными релизами. Userscript v0.7.5 не изменён. Публикация в Chrome Web Store ещё не выполнена.
