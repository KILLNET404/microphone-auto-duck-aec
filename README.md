## Для чего нужен проект

Смотришь стрим или фильм и одновременно диктуешь сообщение в ChatGPT либо разговариваешь через браузер? Звук видео может мешать голосовому вводу и попадать в микрофон. **Microphone Auto Duck + AEC** автоматически приглушает поддерживаемые HTML5-плееры, пока браузер использует микрофон, и возвращает прежнюю громкость после записи. Дополнительно может запросить отключение эхоподавления (AEC).

Версии и история изменений ведутся отдельно. Не запускайте обе реализации одновременно: возможен конфликт управления громкостью.

## Для чего отключается эхоподавление (AEC)

Основная цель этой настройки — **более чёткая голосовая диктовка**, например при вводе текста в ChatGPT. В некоторых условиях встроенное браузерное эхоподавление слишком активно обрабатывает голос: может ослаблять звуки, «съедать» слоги и окончания слов. Из-за этого распознавание речи иногда ошибается.

Обе реализации **запрашивают** отключение AEC, чтобы при таких настройках оборудования голос передавался естественнее. Одновременно он автоматически приглушает поддерживаемые видео- и аудиоплееры, чтобы их звук меньше попадал в микрофон.

**Важно:** это не гарантирует улучшение распознавания на любом устройстве. Браузер или сайт может игнорировать запрос отключения AEC; при разговорах через динамики без эхоподавления иногда появляется эхо.

## Проверенные площадки

Для userscript работа приглушения проверена на **VK Видео Live, VK Видео, YouTube, Kick, Boosty и Twitch**. Расширение протестировано автором в Яндекс Браузере; отдельная проверка всех перечисленных площадок в расширении не заявляется.

## Установка

### Userscript

1. Установите совместимый менеджер пользовательских скриптов с поддержкой `GM_*` API.
2. Откройте [Greasy Fork](https://greasyfork.org/ru/scripts/607125-microphone-auto-duck-aec) и нажмите «Установить». Можно также импортировать [файл скрипта](Scripts/Microphone_Auto_Duck_AEC.user.js) вручную.
3. Отключите другие версии проекта и обновите открытые вкладки.

### Chromium Extension

Публикация в Chrome Web Store готовится. Для локальной установки:

1. Скачайте репозиторий через Code → Download ZIP и распакуйте его.
2. Откройте `chrome://extensions` (Chrome) или `browser://extensions` (Яндекс Браузер).
3. Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку [`Extension`](Extension/), содержащую `manifest.json`.
4. Отключите userscript проекта, если он установлен, и обновите открытые вкладки.
5. Нажмите значок расширения для настройки громкости и быстрого включения или выключения приглушения. Зелёная точка означает включённый режим, красная — выключенный.

## Ограничения

- Управление громкостью HTML5-плееров, а не системным микшером.
- Закрытые Shadow DOM, нестандартные плееры и некоторые iframe могут не поддерживаться. Отслеживание микрофона и запрос AEC выполняются в верхнем документе.
- Не все способы использования микрофона доступны для отслеживания.
- Браузер или сайт может проигнорировать запрос отключения AEC; при звонках через динамики возможно эхо.
- Переключатель расширения отключает автоматическое приглушение, но не отменяет запрос отключения AEC.
