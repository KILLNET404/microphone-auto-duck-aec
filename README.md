# Microphone Auto Duck + AEC

**Текущая стабильная версия:** `0.7.5`  
**Автор:** `KILLNET_404`  
**Тип проекта:** бесплатный пользовательский скрипт для браузера (userscript).

**[Установить скрипт на Greasy Fork](https://greasyfork.org/ru/scripts/607125-microphone-auto-duck-aec)** · [Поддержать разработку](https://killnet404.github.io/support/) · [Telegram-канал](https://t.me/DevUndergroundLab)

## Для чего нужен скрипт

Смотришь стрим или фильм и одновременно диктуешь сообщение в ChatGPT либо разговариваешь через браузер? Звук видео может мешать голосовому вводу и попадать в микрофон. **Microphone Auto Duck + AEC** автоматически приглушает поддерживаемые HTML5-плееры, пока браузер использует микрофон, и возвращает прежнюю громкость после записи. Дополнительно скрипт может запросить отключение эхоподавления (AEC), если оно искажает голос при диктовке.

## Возможности

- Уровни остаточной громкости **5%, 7% и 10%** (по умолчанию 5%).
- Автоматическое приглушение и восстановление исходной громкости.
- Поддержка плееров в обычном DOM и доступных открытых Shadow DOM, включая динамически появляющиеся элементы.
- Обнаружение HTML5-плееров внутри HTTP(S) iframe, в том числе на других доменах.
- В iframe выполняется облегчённое управление громкостью; отслеживание микрофона и AEC работают только на основной странице.
- Без ручных горячих клавиш и лишних всплывающих уведомлений.


## Для чего отключается эхоподавление (AEC)

Основная цель этой настройки — **более чёткая голосовая диктовка**, например при вводе текста в ChatGPT. В некоторых условиях встроенное браузерное эхоподавление слишком активно обрабатывает голос: может ослаблять звуки, «съедать» слоги и окончания слов. Из-за этого распознавание речи иногда ошибается.

Скрипт **запрашивает** отключение AEC, чтобы при таких настройках оборудования голос передавался естественнее. Одновременно он автоматически приглушает поддерживаемые видео- и аудиоплееры, чтобы их звук меньше попадал в микрофон.

**Важно:** это не гарантирует улучшение распознавания на любом устройстве. Браузер или сайт может игнорировать запрос отключения AEC; при разговорах через динамики без эхоподавления иногда появляется эхо.

## Проверенные площадки

Работа приглушения проверена пользователем на **VK Видео Live, VK Видео, YouTube, Kick, Boosty и Twitch**.

Это не закрытый список совместимых сайтов. Скрипт рассчитан на HTML5-плееры в разных веб-сервисах; фактическая поддержка зависит от реализации плеера, браузера и разрешений менеджера пользовательских скриптов.

## Установка

1. Установите совместимое расширение для пользовательских скриптов (userscript manager) с поддержкой требуемых `GM_*` API.
2. Откройте [страницу скрипта на Greasy Fork](https://greasyfork.org/ru/scripts/607125-microphone-auto-duck-aec) и нажмите «Установить». Альтернативно можно импортировать файл [`Scripts/Microphone_Auto_Duck_AEC.user.js`](Scripts/Microphone_Auto_Duck_AEC.user.js) вручную.
3. Отключите предыдущие версии Auto Duck/AEC, чтобы они не конфликтовали, и обновите открытые вкладки.

## Ограничения

- Скрипт регулирует громкость HTML5-плееров в браузере, а не общую громкость системы.
- Некоторые нестандартные плееры, закрытые Shadow DOM и недоступные iframe могут не поддерживаться.
- Не все способы захвата микрофона доступны для отслеживания через userscript.
- Запрос `echoCancellation: false` может быть проигнорирован браузером или сайтом. В звонках с открытыми динамиками отключение AEC иногда вызывает эхо для собеседников.
